## 题目描述

给定一个 `m x n` 的矩阵 `matrix`，如果某个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。

请输出置零后的矩阵。只有**原始**矩阵中的 `0` 会触发其所在行、列被置零，由置零操作新写入的 `0` 不会继续连锁扩散。

请使用原地算法。

## 输入格式

第一行两个整数 `m` `n`，表示矩阵的行数和列数。

随后 `m` 行，每行 `n` 个整数，空格分隔，表示矩阵。

## 输出格式

输出置零后的矩阵，格式与输入相同：第一行两个整数 `m` `n`，随后 `m` 行，每行 `n` 个整数，空格分隔。

## 样例
### 样例 1
输入：
```text
3 3
1 1 1
1 0 1
1 1 1
```
输出：
```text
3 3
1 0 1
0 0 0
1 0 1
```

### 样例 2
输入：
```text
3 4
0 1 2 0
3 4 5 2
1 3 1 5
```
输出：
```text
3 4
0 0 0 0
0 4 5 0
0 3 1 0
```

## 提示（数据范围）

- `1 <= m, n <= 200`
- `-2^{31} <= matrix[i][j] <= 2^{31} - 1`
