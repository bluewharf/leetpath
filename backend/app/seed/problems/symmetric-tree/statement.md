## 题目描述

给你一个二叉树的根节点 `root`，检查它是否沿中心轴镜像对称。

即以根为中心，左子树与右子树互为镜像：对应位置的节点值相等，且一侧的左子树与另一侧的右子树、一侧的右子树与另一侧的左子树分别互为镜像。

空树视为对称。

## 输入格式

第一行一个整数 `n`，表示层序序列中的 token 个数。

若 `n = 0`，输入只有一行 `0`，表示空树。

若 `n > 0`，第二行 `n` 个 token，为二叉树的层序遍历：非空节点为整数，空位为 `null`。末尾连续的 `null` 省略。

## 输出格式

一行，若该树对称则输出 `true`，否则输出 `false`（小写）。

## 样例

### 样例 1

输入：

```text
7
1 2 2 3 4 4 3
```

输出：

```text
true
```

### 样例 2

输入：

```text
7
1 2 2 null 3 null 3
```

输出：

```text
false
```

## 提示（数据范围）

- `0 <= n <= 1000`
- `-100 <= 节点值 <= 100`
- 空树视为对称
