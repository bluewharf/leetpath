## 题目描述

给定 `n` 个节点（编号 `0 .. n-1`）和若干有向边。边 `a b` 表示必须 **先完成 `b` 再完成 `a`**（与课程表先修关系相同：要学 `a` 得先学 `b`）。

请输出一种合法的完成顺序。若图中有环，无法排出顺序，输出空（不输出任何节点）。

若存在多种合法顺序，输出 **字典序最小** 的序列（每次选当前入度为 0 的编号最小节点）。

站点热题「课程表」只问能不能修完（`true`/`false`）。本题要排出顺序并判环，不要盖到那一题上。

## 输入格式

第一行一个整数 `n`，表示节点个数。

随后是边构成的二维数组：第一行两个整数 `m` 和 `2`，其中 `m` 为边数。

若 `m > 0`，随后 `m` 行，每行两个整数 `a b`。若 `m = 0`，则只有一行 `0 2`。

## 输出格式

若无环：一行 `n` 个整数，空格分隔，为字典序最小的拓扑序。

若有环：不输出任何内容。

## 样例

### 样例 1

输入：

```text
2
1 2
1 0
```

输出：

```text
0 1
```

解释：要完成 `1` 必须先完成 `0`。

### 样例 2

输入：

```text
2
2 2
1 0
0 1
```

输出：

```text

```

解释：互相先修，有环。

## 提示（数据范围）

- `1 <= n <= 2000`
- `0 <= m <= 5000`
- `0 <= a, b < n`
