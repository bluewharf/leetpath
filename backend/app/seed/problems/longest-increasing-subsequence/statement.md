## 题目描述

给你一个整数数组 `nums`，请你找出其中最长**严格递增**子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。子序列不要求连续，但必须保持相对顺序。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数，空格分隔，表示 `nums`。

## 输出格式

输出一个整数，表示最长严格递增子序列的长度。

## 样例
### 样例 1
输入：
```text
8
10 9 2 5 3 7 101 18
```
输出：
```text
4
```

解释：最长严格递增子序列为 `[2,3,7,101]`、`[2,5,7,101]` 或 `[2,3,7,18]`，长度为 `4`。

### 样例 2
输入：
```text
6
0 1 0 3 2 3
```
输出：
```text
4
```

解释：最长严格递增子序列为 `[0,1,2,3]`，长度为 `4`。

## 提示（数据范围）

- `1 <= n <= 2500`
- `-10^4 <= nums[i] <= 10^4`
- 要求**严格递增**，相等元素不能同时出现在子序列中
