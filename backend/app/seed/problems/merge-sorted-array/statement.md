## 题目描述

给定两个已经 **非递减** 排序的整数数组 `nums1`、`nums2`，请把它们合并成一个非递减数组并输出。

可以有重复值。不要先拼再整体排序。这不是「合并两个有序链表」：输入输出都是数组。

## 输入格式

依次给出两个数组：

第一行一个整数 `n`，表示 `nums1` 的长度。若 `n > 0`，第二行 `n` 个整数；若 `n = 0`，省略该行。

接下来一行一个整数 `m`。若 `m > 0`，再下一行 `m` 个整数；若 `m = 0`，省略该行。

## 输出格式

一行，合并后的数组，以空格分隔。两个数组都空时输出空行。

## 样例

### 样例 1

输入：

```text
3
1 2 3
3
2 5 6
```

输出：

```text
1 2 2 3 5 6
```

### 样例 2

输入：

```text
1
1
0
```

输出：

```text
1
```

### 样例 3

输入：

```text
0
1
1
```

输出：

```text
1
```


## 提示（数据范围）

- `0 <= n, m <= 10^4`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`
