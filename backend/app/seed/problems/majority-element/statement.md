## 题目描述

给定一个大小为 `n` 的数组 `nums`，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

## 输出格式

一行一个整数，表示多数元素。

## 样例

### 样例 1

输入：

```text
3
3 2 3
```

输出：

```text
3
```

### 样例 2

输入：

```text
7
2 2 1 1 1 2 2
```

输出：

```text
2
```

## 提示（数据范围）

- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- 数组总是存在多数元素
