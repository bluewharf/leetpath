## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。`n = 0` 时只有一行 `0`。

## 输出格式

第一行一个整数 `m`，表示反转后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，为空格分隔的节点值。空链表输出一行 `0`。

## 样例

### 样例 1

输入：

```text
5
1 2 3 4 5
```

输出：

```text
5
5 4 3 2 1
```

### 样例 2

输入：

```text
2
1 2
```

输出：

```text
2
2 1
```

### 样例 3

输入：

```text
0
```

输出：

```text
0
```


## 提示（数据范围）

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`
