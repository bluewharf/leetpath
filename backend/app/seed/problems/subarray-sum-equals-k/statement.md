## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的子数组的个数。

子数组是数组中元素的连续非空序列。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

第三行一个整数 `k`。

## 输出格式

一行一个整数，表示和为 `k` 的子数组个数。

## 样例

### 样例 1

输入：

```text
3
1 1 1
2
```

输出：

```text
2
```

### 样例 2

输入：

```text
3
1 2 3
3
```

输出：

```text
2
```

## 提示（数据范围）

- `1 <= n <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`
