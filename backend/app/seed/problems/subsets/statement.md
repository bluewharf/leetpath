## 题目描述

给你一个整数数组 `nums`，数组中的元素 **互不相同**。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。

为保证输出确定：每个子集内部元素按升序排列；所有子集按 **(长度, 字典序)** 排序后逐行输出。空子集长度为 0，对应一个 **空行**，因此总是出现在输出的第一行。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`。

## 输出格式

共 `2^n` 行，每行一个子集：

- 空子集输出空行；
- 非空子集：元素已按升序排列，以空格分隔。

所有子集已按 (长度, 字典序) 排序（先按长度升序，长度相同则按序列字典序）。

## 样例

### 样例 1

输入：

```text
3
1 2 3
```

输出：

```text

1
2
3
1 2
1 3
2 3
1 2 3
```

### 样例 2

输入：

```text
1
0
```

输出：

```text

0
```

## 提示（数据范围）

- `1 <= n <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有整数互不相同
