## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。

异位词指由相同字母重排列形成的字符串（包括相同的字符串）。

输出起始下标数组，按下标升序排列，以空格分隔。

## 输入格式

第一行字符串 `s`。

第二行字符串 `p`。

## 输出格式

一行若干个整数，表示所有异位词子串的起始下标（升序，空格分隔）。

若没有符合条件的起始下标，则输出空行。

## 样例

### 样例 1

输入：

```text
cbaebabacd
abc
```

输出：

```text
0 6
```

### 样例 2

输入：

```text
abab
ab
```

输出：

```text
0 1 2
```

## 提示（数据范围）

- `1 <= |s|, |p| <= 3 * 10^4`
- `s` 和 `p` 仅包含小写英文字母
