## 题目描述

数字 `n` 代表生成括号的对数，请你生成所有可能的并且 **有效的** 括号组合。

有效括号组合需满足：左括号必须用相同数量的右括号闭合，且任何前缀中左括号的数量不少于右括号。

为保证输出确定：每个合法括号串一行，按字典序输出。

## 输入格式

一行一个整数 `n`，表示括号对数。

## 输出格式

若干行，每行一个长度为 `2n` 的合法括号串。

每个合法括号串一行，按字典序输出。

## 样例

### 样例 1

输入：

```text
3
```

输出：

```text
((()))
(()())
(())()
()(())
()()()
```

### 样例 2

输入：

```text
1
```

输出：

```text
()
```

## 提示（数据范围）

- `1 <= n <= 8`
