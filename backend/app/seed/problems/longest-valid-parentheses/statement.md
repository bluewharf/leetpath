## 题目描述

给定一个只包含 `'('` 和 `')'` 的字符串 `s`，找出最长有效（格式正确且连续）括号子串的长度。

有效括号子串是左右括号匹配正确的 **连续子串**（不是子序列）。

## 输入格式

一行字符串 `s`，仅含 `'('` 与 `')'`。可以为空行，表示空串。

## 输出格式

一行一个整数，表示最长有效括号子串的长度。

## 样例

### 样例 1

输入：

```text
(()
```

输出：

```text
2
```

最长有效子串为 `"()"`，长度为 2。

### 样例 2

输入：

```text
)()())
```

输出：

```text
4
```

最长有效子串为 `"()()"`，长度为 4。

## 提示（数据范围）

- `0 <= |s| <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`
