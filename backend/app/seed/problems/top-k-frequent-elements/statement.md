## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。

为保证输出确定：按元素出现频次 **从高到低** 排列；若频次相同，则按元素值 **从小到大** 排列。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`。

第三行一个整数 `k`。

## 输出格式

一行 `k` 个整数，以空格分隔，表示前 `k` 个高频元素。顺序为：频次从高到低；频次相同则元素值从小到大。

## 样例

### 样例 1

输入：

```text
6
1 1 1 2 2 3
2
```

输出：

```text
1 2
```

### 样例 2

输入：

```text
1
1
1
```

输出：

```text
1
```

## 提示（数据范围）

- `1 <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= 数组中不同元素的个数`
