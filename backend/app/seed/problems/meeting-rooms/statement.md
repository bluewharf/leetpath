## 题目描述

给定一组会议时间区间，每个区间为 `[start, end)`（左闭右开）。请判断 **一个人** 能否参加全部会议，也就是这些区间是否两两不重叠。

端点相接（一场结束时刻等于下一场开始）视为不重叠，赶得及。本题只判断能否全参加，不是选最大不重叠子集，也不是合并区间。

快手口述「一组区间是否互不重叠」与蚂蚁「一个人能否参加完全部会议」是同一判断。

## 输入格式

第一行两个整数 `m` 和 `n`，其中 `m` 为区间个数，`n` 恒为 `2`。

若 `m > 0`，随后 `m` 行，每行两个整数 `start end`。若 `m = 0`，只有一行 `0 2`。

## 输出格式

一行 `true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
3 2
0 30
5 10
15 20
```

输出：

```text
false
```

### 样例 2

输入：

```text
2 2
7 10
2 4
```

输出：

```text
true
```

## 提示（数据范围）

- `0 <= m <= 10^4`
- `0 <= start < end <= 10^6`
