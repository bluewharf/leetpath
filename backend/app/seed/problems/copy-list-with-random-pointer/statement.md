## 题目描述

给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random`，该指针可以指向链表中的任何节点或空节点。

请构造这个链表的 **深拷贝**。深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点**。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y`，那么在复制链表中对应的两个节点 `x` 和 `y`，同样有 `x.random --> y`。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n = 0`，输入只有一行 `0`，表示空链表。

若 `n > 0`，随后 `n` 行，第 `i` 行两个整数 `val randomIndex`（`0 <= i < n`），表示下标为 `i` 的节点的值，以及其 `random` 指向的节点下标（从 0 开始）。`randomIndex = -1` 表示 `random` 为空。节点按 `next` 顺序给出，即下标 `0, 1, ..., n-1` 依次相连。

## 输出格式

输出复制后链表，格式与输入相同：第一行 `n`，随后 `n` 行每行 `val randomIndex`（`random` 为空时 `randomIndex` 为 `-1`）。下标相对于复制后的链表。空链表输出一行 `0`。

## 样例

### 样例 1

输入：

```text
5
7 -1
13 0
11 4
10 2
1 0
```

输出：

```text
5
7 -1
13 0
11 4
10 2
1 0
```

### 样例 2

输入：

```text
2
1 1
2 1
```

输出：

```text
2
1 1
2 1
```

## 提示（数据范围）

- `0 <= n <= 1000`（实际测试数据规模保证参考解在时限一半内跑完，单文件不超过 64KB）
- `-10^4 <= Node.val <= 10^4`
- `randomIndex` 为 `-1` 或区间 `[0, n-1]` 内的整数
