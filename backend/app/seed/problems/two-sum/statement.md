## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

请返回下标较小者在前、较大者在后。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

第三行一个整数 `target`。

## 输出格式

一行两个整数，表示两个下标，**较小下标在前**，以空格分隔。

## 样例

### 样例 1

输入：

```text
4
2 7 11 15
9
```

输出：

```text
0 1
```

### 样例 2

输入：

```text
3
3 2 4
6
```

输出：

```text
1 2
```

## 提示（数据范围）

- `2 <= n <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- 只会存在一个有效答案
