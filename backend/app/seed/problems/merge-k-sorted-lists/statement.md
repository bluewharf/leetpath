## 题目描述

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

## 输入格式

第一行一个整数 `k`，表示链表的个数。

随后给出 `k` 个链表。每个链表的格式为：第一行一个整数 `n`，表示该链表的节点个数；若 `n > 0`，下一行 `n` 个整数，表示该链表从前往后的节点值（已按非递减顺序排列）。若某个链表为空，则该链表仅占一行 `0`。

`k = 0` 时输入只有一行 `0`，表示没有链表（结果为空链表）。

## 输出格式

第一行一个整数 `m`，表示合并后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，表示合并后链表从前往后的节点值。

若结果为空链表，仅输出一行 `0`。

## 样例

### 样例 1

输入：

```text
3
3
1 4 5
3
1 3 4
2
2 6
```

输出：

```text
8
1 1 2 3 4 4 5 6
```

### 样例 2

输入：

```text
0
```

输出：

```text
0
```

### 样例 3

输入：

```text
1
0
```

输出：

```text
0
```


## 提示（数据范围）

- `0 <= k <= 10^4`
- `0 <= 每个链表的节点数 <= 500`
- 所有链表的节点总数不超过 `10^4`
- `-10^4 <= 节点值 <= 10^4`
- 每个链表已按非递减顺序排列
