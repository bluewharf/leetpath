## 题目描述

给定一个仅包含数字 `2-9` 的字符串 `digits`，返回所有它能表示的字母组合。

数字到字母的映射如下（与电话按键相同）。注意 `1` 不对应任何字母。

- `2` → `abc`
- `3` → `def`
- `4` → `ghi`
- `5` → `jkl`
- `6` → `mno`
- `7` → `pqrs`
- `8` → `tuv`
- `9` → `wxyz`

为保证输出确定：将所有字母组合按字典序逐行输出，每行一个组合（不含空格）。若输入为空则不输出任何内容。

## 输入格式

一行字符串 `digits`（可能为空行）。

## 输出格式

若干行，每行一个字母组合。

所有组合按字典序输出。

若输入为空，则不输出任何内容。

## 样例

### 样例 1

输入：

```text
23
```

输出：

```text
ad
ae
af
bd
be
bf
cd
ce
cf
```

### 样例 2

输入：

```text

```

输出：

```text
```

## 提示（数据范围）

- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 内的一个数字
- 组合数量最多为 `4^4 = 256`
