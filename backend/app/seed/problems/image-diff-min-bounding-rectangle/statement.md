## 题目描述

给定两张 **同尺寸** 的整数像素图 `A`、`B`（每个格子一个整数）。请找出所有像素值不同的格子，返回它们的 **轴对齐最小包围矩形**。

矩形用四个整数表示：`r1 c1 r2 c2`，均为 **从 0 开始** 的行列下标，`(r1, c1)` 是左上（含），`(r2, c2)` 是右下（含）。

若两图完全相同，没有差异点，输出一行 `-1`。本题只要求轴对齐矩形，不要求可旋转的最小面积矩形。

## 输入格式

先给出图 `A`：第一行两个整数 `m` `n`，随后 `m` 行每行 `n` 个整数。

再给出图 `B`：第一行两个整数 `m2` `n2`（保证与 `A` 同尺寸），随后 `m2` 行每行 `n2` 个整数。

## 输出格式

若存在差异：一行四个整数 `r1 c1 r2 c2`，以空格分隔。

若完全相同：一行 `-1`。

## 样例

### 样例 1

输入：

```text
2 3
1 2 3
4 5 6
2 3
1 2 0
4 5 6
```

输出：

```text
0 2 0 2
```

### 样例 2

输入：

```text
1 1
7
1 1
7
```

输出：

```text
-1
```

## 提示（数据范围）

- `1 <= m, n <= 200`
- `-10^6 <= 像素值 <= 10^6`
