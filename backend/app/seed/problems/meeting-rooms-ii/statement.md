## 题目描述

给定一组会议时间区间，每个区间为 `[start, end)`（左闭右开）。时间不冲突的会议可以共用一间会议室。请计算安排完所有会议所需的 **最少会议室数量**。

端点相接（一场结束时刻等于另一场开始）可以共用同一间会议室。最少会议室数等于同一时刻正在进行的最大场数。

## 输入格式

第一行两个整数 `m` 和 `n`，其中 `m` 为区间个数，`n` 恒为 `2`。

若 `m > 0`，随后 `m` 行，每行两个整数 `start end`。若 `m = 0`，只有一行 `0 2`。

## 输出格式

一行一个整数，表示最少会议室数量。

## 样例

### 样例 1

输入：

```text
3 2
0 30
5 10
15 20
```

输出：

```text
2
```

### 样例 2

输入：

```text
1 2
7 10
```

输出：

```text
1
```

## 提示（数据范围）

- `0 <= m <= 10^4`
- `0 <= start < end <= 10^6`
