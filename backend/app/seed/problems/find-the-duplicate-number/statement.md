## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`）。可知至少存在一个重复的整数。

假设 `nums` 只有 **一个重复的整数**，返回 **这个重复的数**。

你设计的解决方案必须 **不修改** 数组 `nums`，并且只用常量级 `O(1)` 的额外空间。

## 输入格式

第一行一个整数 `len`，表示数组长度（等于 `n + 1`）。

第二行 `len` 个整数，空格分隔，表示 `nums`。

## 输出格式

输出一个整数，表示数组中唯一的那个重复数字。

## 样例

### 样例 1

输入：

```text
5
1 3 4 2 2
```

输出：

```text
2
```

### 样例 2

输入：

```text
5
3 1 3 4 2
```

输出：

```text
3
```

## 提示（数据范围）

- `1 <= n <= 10^5`
- `nums.length == n + 1`
- `1 <= nums[i] <= n`
- `nums` 中只有一个重复的数字，它可能出现两次或更多次
- 实际测试数据规模保证参考解在时限一半内跑完，单文件不超过 64KB
