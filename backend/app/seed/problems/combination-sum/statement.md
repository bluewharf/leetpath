## 题目描述

给你一个由**互不相同**的正整数组成的数组 `candidates` 和一个目标整数 `target`，请你找出 `candidates` 中可以使数字和为目标数 `target` 的所有不同组合。

`candidates` 中的同一个数字可以无限制重复被选取。如果至少有一个数字的选取次数不同，则两种组合视为不同。

答案中不可以包含重复的组合（作为多重集合相同的组合只输出一次）。

为保证输出确定：每个组合内部按升序排列，数字之间以空格分隔，每行一个组合；所有组合按字典序逐行输出。若没有任何合法组合，则不输出任何内容。

## 输入格式

第一行一个整数 `n`，表示数组 `candidates` 的长度。

第二行 `n` 个互不相同的整数 `candidates[0] .. candidates[n-1]`（空格分隔）。

第三行一个整数 `target`，表示目标和。

## 输出格式

若干行，每行一个组合（组合内数字升序，以空格分隔）。

所有组合按字典序输出。

若无解，则不输出任何内容。

## 样例

### 样例 1

输入：

```text
4
2 3 6 7
7
```

输出：

```text
2 2 3
7
```

解释：`2 + 2 + 3 = 7`（`2` 可被重复选取），`7 = 7`。`[2, 2, 3]` 的字典序小于 `[7]`。

### 样例 2

输入：

```text
3
2 3 5
8
```

输出：

```text
2 2 2 2
2 3 3
3 5
```

## 提示（数据范围）

- `1 <= n <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 中的全部元素各不相同
- `1 <= target <= 40`
