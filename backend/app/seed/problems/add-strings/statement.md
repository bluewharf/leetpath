## 题目描述

给定两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和并同样以字符串形式返回。

你不能使用任何内置的处理大整数的库，也不能直接把输入转换成整数类型。

这不是链表「两数相加」：输入是数字字符串，高位在左。

## 输入格式

第一行字符串 `num1`（可能为空行，视为 `0`）。

第二行字符串 `num2`（可能为空行，视为 `0`）。

## 输出格式

一行，表示和的十进制字符串，除数字 `0` 本身外不含前导零。

## 样例

### 样例 1

输入：

```text
11
123
```

输出：

```text
134
```

### 样例 2

输入：

```text
456
77
```

输出：

```text
533
```

### 样例 3

输入：

```text
0
0
```

输出：

```text
0
```


## 提示（数据范围）

- `0 <= num1.length, num2.length <= 10^4`
- `num1` 和 `num2` 只包含数字 `0-9`（空行视为 0）
