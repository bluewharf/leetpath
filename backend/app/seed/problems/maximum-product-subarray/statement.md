## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的**非空连续子数组**（该子数组至少包含一个元素），并返回该子数组所对应的乘积。

子数组是数组中一段**连续**的部分，不能跳过中间的元素。例如 `[-2, 0, -1]` 中不能选取 `[-2, -1]`，因为二者不相邻。

测试数据保证答案是 32 位有符号整数。答案**可能为负数**：例如数组只含一个负数，或全为负数且长度为奇数时，整体乘积为负，此时最大乘积可能是某个较短连续子数组的乘积（甚至是单个元素本身）。若能取到偶数个相邻负数，其乘积为正，应与其它连续子数组比较后取最大。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数，空格分隔，表示 `nums`。

## 输出格式

输出一个整数，表示乘积最大的连续子数组的乘积。

## 样例
### 样例 1
输入：
```text
4
2 3 -2 4
```
输出：
```text
6
```

解释：子数组 `[2, 3]` 的乘积为 `6`，为最大。

### 样例 2
输入：
```text
3
-2 0 -1
```
输出：
```text
0
```

解释：不能使用 `[-2, -1]`，因为二者不连续。结果为 `0`。

## 提示（数据范围）

- `1 <= n <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- 任意前缀或后缀的乘积均保证在 32 位有符号整数范围内
