## 题目描述

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测时使用整数 `pos` 表示链表尾部连接到的节点下标（从 0 开始）。如果 `pos` 为 `-1`，则该链表没有环。注意：`pos` 不作为算法的参数传入，只用于构造输入链表。

请判断链表是否为环形链表。若存在环输出 `true`，否则输出 `false`。

进阶：你能用 \(O(1)\)（即常量）内存解决此问题吗？

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行给出 `n` 个空格分隔的整数，为链表从前往后的节点值（尚未成环）。

最后一行一个整数 `pos`：链表尾连接到的节点下标（从 0 开始）；无环时 `pos = -1`。

若 `n = 0`，输入共两行：第一行 `0`，第二行 `pos`（通常为 `-1`）。

构造方式：先用这 `n` 个节点按顺序连成一条链表；若 `pos >= 0`，则将最后一个节点的 `next` 指向下标为 `pos` 的节点。

## 输出格式

输出一行：`true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
4
3 2 0 -4
1
```

输出：

```text
true
```

链表中有一个环，其尾部连接到第二个节点（下标 1）。

### 样例 2

输入：

```text
2
1 2
0
```

输出：

```text
true
```

链表中有一个环，其尾部连接到第一个节点（下标 0）。

## 提示（数据范围）

- \(0 \le n \le 10^4\)
- \(-10^5 \le \text{Node.val} \le 10^5\)
- `pos` 为 `-1` 或区间 \([0, n-1]\) 内的整数
- 单个测试文件不超过 64KB
