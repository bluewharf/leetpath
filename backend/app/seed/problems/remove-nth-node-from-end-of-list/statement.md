## 题目描述

给你一个链表，删除链表的倒数第 `k` 个结点，并返回链表的头结点。

倒数第 `k` 个结点是从链表末尾往前数的第 `k` 个结点（从 1 开始计数）。例如链表 `1 → 2 → 3 → 4 → 5`，当 `k = 2` 时删除的是值为 `4` 的结点。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。

最后一行一个整数 `k`，表示要删除的倒数第 `k` 个结点。

## 输出格式

第一行一个整数 `m`，表示删除后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，为空格分隔的节点值。若删除后为空链表，仅输出一行 `0`。

## 样例

### 样例 1

输入：

```text
5
1 2 3 4 5
2
```

输出：

```text
4
1 2 3 5
```

原链表为 `1 → 2 → 3 → 4 → 5`，删除倒数第 2 个结点（值为 `4`）后得到 `1 → 2 → 3 → 5`。

### 样例 2

输入：

```text
1
1
1
```

输出：

```text
0
```

链表仅有一个结点，删除倒数第 1 个结点后为空链表。

### 样例 3

输入：

```text
2
1 2
1
```

输出：

```text
1
1
```


## 提示（数据范围）

- `1 <= n <= 30`
- `1 <= k <= n`
- `0 <= Node.val <= 100`
