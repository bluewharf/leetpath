## 题目描述

给你二叉树的根结点 `root`，请你将它展开为一个单链表：

- 展开后的单链表同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null`。
- 展开后的单链表应该与二叉树 **先序遍历** 顺序相同。

请返回展开后的树。因左子指针全为 `null`，层序序列形态为「值 `null` 值 `null` …」。

## 输入格式

输入为一棵二叉树的层序序列：

- 第一行一个整数 `n`，表示层序 token 个数。
- 若 `n = 0`，输入只有一行 `0`，表示空树。
- 若 `n > 0`，第二行 `n` 个以空格分隔的 token：非空节点为整数，空位为 `null`。末尾连续的 `null` 已省略。

## 输出格式

输出展开后的二叉树，序列化规则与输入相同：

- 空树输出一行 `0`。
- 非空树第一行输出 token 个数 `m`，第二行输出 `m` 个层序 token（空位为 `null`，**末尾连续的 `null` 必须省略**）。

展开后每个节点的左子均为空、右子指向先序后继，因此非空结果形如：

```text
11
1 null 2 null 3 null 4 null 5 null 6
```

## 样例

### 样例 1

输入：

```text
7
1 2 5 3 4 null 6
```

输出：

```text
11
1 null 2 null 3 null 4 null 5 null 6
```

原树先序为 `1, 2, 3, 4, 5, 6`，展开后沿 `right` 链接成该顺序。

### 样例 2

输入：

```text
0
```

输出：

```text
0
```

## 提示（数据范围）

- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`
