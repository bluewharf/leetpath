## 题目描述

给定一个二叉树的根节点 `root`，返回其节点值的 **中序遍历**。

中序遍历的访问顺序为：先递归遍历左子树，再访问根节点，再递归遍历右子树。

## 输入格式

输入一棵二叉树：第一行一个整数 `n`，表示层序序列中的 token 个数。

若 `n = 0`，输入只有一行 `0`，表示空树。

若 `n > 0`，第二行 `n` 个 token，为二叉树的 **层序遍历**：非空节点为整数，空子节点位置用 `null` 表示。末尾连续的 `null` 省略。

例如，力扣数组形式 `[1,null,2,3]` 对应：

```text
4
1 null 2 3
```

其结构为根节点 `1`，左子树为空，右子节点为 `2`，`2` 的左子节点为 `3`。

## 输出格式

输出中序遍历的节点值，以空格分隔，占一行。空树不输出任何内容（或空行）。

## 样例

### 样例 1

输入：

```text
4
1 null 2 3
```

输出：

```text
1 3 2
```

### 样例 2

输入：

```text
0
```

输出：

```text
```

### 样例 3

输入：

```text
1
1
```

输出：

```text
1
```


## 提示（数据范围）

- 二叉树节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`
