## 题目描述

编写一个高效的算法来判断 `m x n` 矩阵中是否存在一个目标值 `target`。该矩阵具有如下特性：

- 每行中的整数从左到右按升序排列。
- 每行的第一个整数大于前一行的最后一个整数。

若目标值存在于矩阵中则输出 `true`，否则输出 `false`。

## 输入格式

第一行两个整数 `m n`，表示矩阵的行数和列数。

随后 `m` 行，每行 `n` 个整数，表示矩阵。

最后一行一个整数 `target`，表示要搜索的目标值。

## 输出格式

输出一行：`true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
3
```

输出：

```text
true
```

### 样例 2

输入：

```text
3 4
1 3 5 7
10 11 16 20
23 30 34 60
13
```

输出：

```text
false
```

## 提示（数据范围）

- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j] <= 10^4`
- `-10^4 <= target <= 10^4`
- 每行中的整数从左到右升序排列
- 每行的第一个整数大于前一行的最后一个整数
