## 题目描述

给定两个等长整数向量 `a`、`b`，计算它们的余弦相似度：

`cos = (a · b) / (|a| |b|)`

其中 `·` 是点积，`|v|` 是 L2 范数。约定：任一向量是零向量（模长为 0）时结果为 `0`。保证两个向量维度相同。

## 输入格式

第一行一个整数 `n`，表示向量 `a` 的长度。若 `n > 0`，第二行 `n` 个整数。

接下来一行一个整数 `m`（保证 `m = n`）。若 `m > 0`，再下一行 `m` 个整数。

## 输出格式

一行一个浮点数，**保留 1 位小数**（例如 `1.0`、`0.0`、`-1.0`）。

## 样例

### 样例 1

输入：

```text
2
1 0
2
1 0
```

输出：

```text
1.0
```

### 样例 2

输入：

```text
2
1 0
2
0 1
```

输出：

```text
0.0
```

## 提示（数据范围）

- `1 <= n <= 1000`
- `-1000 <= a[i], b[i] <= 1000`
