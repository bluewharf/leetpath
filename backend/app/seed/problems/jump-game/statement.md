## 题目描述

给你一个非负整数数组 `nums`，你最初位于数组的第一个下标。数组中的每个元素 `nums[i]` 表示你在下标 `i` 处可以跳跃的最大长度。

判断你是否能够到达最后一个下标。如果可以到达，输出 `true`；否则输出 `false`（小写）。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个非负整数，空格分隔，表示 `nums`。

## 输出格式

输出一行：`true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
5
2 3 1 1 4
```

输出：

```text
true
```

解释：从下标 `0` 跳 `1` 步到达下标 `1`，再从下标 `1` 跳 `3` 步到达最后一个下标。

### 样例 2

输入：

```text
5
3 2 1 0 4
```

输出：

```text
false
```

解释：无论如何都会到达下标 `3`，该处最大跳跃长度为 `0`，无法再前进到达最后一个下标。

## 提示（数据范围）

- `1 <= n <= 10^4`
- `0 <= nums[i] <= 10^5`
