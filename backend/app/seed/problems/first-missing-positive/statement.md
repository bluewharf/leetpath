## 题目描述

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。

请实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`。

## 输出格式

输出一个整数，表示缺失的最小正整数。

## 样例

### 样例 1

输入：

```text
3
1 2 0
```

输出：

```text
3
```

解释：区间 `[1, 2]` 中的数字都在数组中，所以最小缺失正整数是 `3`。

### 样例 2

输入：

```text
4
3 4 -1 1
```

输出：

```text
2
```

解释：`1` 在数组中，但 `2` 缺失。

## 提示（数据范围）

- `1 <= n <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
