## 题目描述

给定二叉树根节点 `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

即：对每一层，从右侧能看到该层最右边的那个节点。

## 输入格式

输入一棵二叉树：第一行一个整数 `n`，表示层序序列中的 token 个数。

若 `n = 0`，输入只有一行 `0`，表示空树。

若 `n > 0`，第二行 `n` 个 token，为二叉树的 **层序遍历**：非空节点为整数，空子节点位置用 `null` 表示。末尾连续的 `null` 省略。

例如，力扣数组形式 `[1,2,3,null,5,null,4]` 对应：

```text
7
1 2 3 null 5 null 4
```

## 输出格式

输出从右侧看到的节点值，从上到下以空格分隔，占一行。空树不输出任何内容（或空行）。

## 样例

### 样例 1

输入：

```text
7
1 2 3 null 5 null 4
```

输出：

```text
1 3 4
```

### 样例 2

输入：

```text
3
1 null 3
```

输出：

```text
1 3
```

## 提示（数据范围）

- 二叉树节点个数的范围是 `[0, 100]`
- `-100 <= Node.val <= 100`
