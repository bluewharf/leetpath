## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

## 输入格式

一行，表示字符串 `s`。

## 输出格式

一行 `true` 或 `false`（小写），表示字符串是否有效。

## 样例

### 样例 1

输入：

```text
()
```

输出：

```text
true
```

### 样例 2

输入：

```text
()[]{}
```

输出：

```text
true
```

### 样例 3

输入：

```text
(]
```

输出：

```text
false
```

### 样例 4

输入：

```text
([])
```

输出：

```text
true
```

### 样例 5

输入：

```text
([)]
```

输出：

```text
false
```


## 提示（数据范围）

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成
