## 题目描述

给你一个整数数组 `nums`，其中元素已经按升序排列，请你将其转换为一棵高度平衡二叉搜索树。高度平衡二叉树是一棵满足「每个节点的左右两个子树的高度差的绝对值不超过 1」的二叉树。

力扣原题允许任意一棵高度平衡 BST，本题为保证答案唯一，构造时对闭区间 `[l, r]` 取 `mid = (l + r + 1) // 2` 作为根（偶数个元素时取偏右中点），再递归构造左右子树。该规则等价于对每个子数组始终取 `mid = len(subarray) // 2`。

## 输入格式

第一行一个整数 `n`，表示数组长度。

若 `n = 0`，输入只有一行 `0`，表示空数组。

若 `n > 0`，第二行 `n` 个严格递增的整数。

## 输出格式

输出按上述偏右中点规则构造得到的二叉搜索树的层序序列（答案唯一）：

- 空树输出单行 `0`。
- 非空树：第一行一个整数 `n`，表示层序 token 个数；第二行 `n` 个 token。空子节点位置用 `null` 表示，**末尾连续的 `null` 必须省略**。

## 样例

### 样例 1

输入：

```text
5
-10 -3 0 5 9
```

输出：

```text
6
0 -3 9 -10 null 5
```

### 样例 2

输入：

```text
2
1 3
```

输出：

```text
2
3 1
```

## 提示（数据范围）

- `0 <= n <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 严格递增
