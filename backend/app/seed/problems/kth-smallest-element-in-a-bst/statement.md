## 题目描述

给定一棵二叉搜索树的根节点 `root` 和整数 `k`，请找出其中第 `k` 小的元素（从 1 开始计数）。

树中节点值互不相同。

## 输入格式

先输入一棵二叉树：第一行一个整数 `n`，第二行 `n` 个 token 为层序遍历序列，空位用 `null` 表示，末尾连续的 `null` 省略。空树输入为单行 `0`。
随后一行一个整数 `k`。

保证给定的树是二叉搜索树，且 `1 <= k <=` 节点数。

## 输出格式

输出一个整数，即第 `k` 小的元素。

## 样例

### 样例 1

输入：

```text
5
3 1 4 null 2
1
```

输出：

```text
1
```

### 样例 2

输入：

```text
8
5 3 6 2 4 null null 1
3
```

输出：

```text
3
```

## 提示（数据范围）

- `1 <=` 节点数 `<= 10^4`
- `1 <= k <=` 节点数
- `-10^4 <= Node.val <= 10^4`
- 节点值互不相同
