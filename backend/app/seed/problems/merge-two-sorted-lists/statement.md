## 题目描述

将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

## 输入格式

先给出第一个链表：第一行整数 `n1`，若 `n1 > 0` 则第二行 `n1` 个按非递减顺序排列的整数；`n1 = 0` 时只有一行 `0`。

再给出第二个链表：一行整数 `n2`，若 `n2 > 0` 则下一行 `n2` 个按非递减顺序排列的整数；`n2 = 0` 时只有一行 `0`。

## 输出格式

第一行一个整数 `m`，表示合并后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，为空格分隔的节点值。空链表输出一行 `0`。

## 样例

### 样例 1

输入：

```text
3
1 2 4
3
1 3 4
```

输出：

```text
6
1 1 2 3 4 4
```

### 样例 2

输入：

```text
0
0
```

输出：

```text
0
```

### 样例 3

输入：

```text
0
1
0
```

输出：

```text
1
0
```


## 提示（数据范围）

- `0 <= n1, n2 <= 50`
- `-100 <= Node.val <= 100`
- 两个链表均按非递减顺序排列
