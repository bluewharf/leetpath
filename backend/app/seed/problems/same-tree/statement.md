## 题目描述

给你两棵二叉树的根节点 `p` 和 `q`，编写一个函数来检验这两棵树是否相同。

如果两个树在结构上相同，并且节点具有相同的值，则认为它们是相同的。左右子树交换后的镜像树 **不算** 相同。

## 输入格式

依次给出两棵二叉树 `p`、`q`。每棵树：第一行一个整数 `n`，若 `n = 0` 表示空树，只有这一行；若 `n > 0`，第二行 `n` 个 token 为层序遍历（空位 `null`，末尾连续 `null` 省略）。

## 输出格式

一行 `true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
3
1 2 3
3
1 2 3
```

输出：

```text
true
```

### 样例 2

输入：

```text
2
1 2
3
1 null 2
```

输出：

```text
false
```

### 样例 3

输入：

```text
3
1 2 1
3
1 1 2
```

输出：

```text
false
```


## 提示（数据范围）

- 每棵树节点数不超过 `100`
- `-10^4 <= 节点值 <= 10^4`
