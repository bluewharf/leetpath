## 题目描述

给定两个整数数组 `preorder` 与 `inorder`，其中 `preorder` 是一棵二叉树的先序遍历，`inorder` 是同一棵树的中序遍历，请构造该二叉树并返回其根节点。

题目保证数组中的值互不相同，且 `preorder`、`inorder` 分别为某棵二叉树的合法先序、中序遍历序列。

## 输入格式

第一行一个整数 `n`，表示 `preorder` 与 `inorder` 的长度。

若 `n = 0`，输入只有一行 `0`。

若 `n > 0`，第二行 `n` 个整数为先序遍历 `preorder`，第三行 `n` 个整数为中序遍历 `inorder`。

## 输出格式

输出构造得到的二叉树的层序序列：第一行一个整数 `m`，表示 token 个数；第二行 `m` 个 token（空位用 `null` 表示，末尾连续的 `null` 省略）。空树输出单行 `0`。

## 样例

### 样例 1

输入：

```text
5
3 9 20 15 7
9 3 15 20 7
```

输出：

```text
7
3 9 20 null null 15 7
```

### 样例 2

输入：

```text
1
-1
-1
```

输出：

```text
1
-1
```

## 提示（数据范围）

- `1 <= n <= 3000`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 与 `inorder` 长度相等
- 数组中的值互不相同
- `preorder` 保证为二叉树的前序遍历序列
- `inorder` 保证为二叉树的中序遍历序列
