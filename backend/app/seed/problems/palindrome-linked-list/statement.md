## 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，输出 `true`；否则输出 `false`。

回文链表指从前往后与从后往前读节点值序列相同。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。`n = 0` 时只有一行 `0`。

## 输出格式

输出一行：`true` 或 `false`（小写）。空链表视为回文。

## 样例

### 样例 1

输入：

```text
4
1 2 2 1
```

输出：

```text
true
```

### 样例 2

输入：

```text
2
1 2
```

输出：

```text
false
```

## 提示（数据范围）

- 链表中节点数目在范围 `[0, 10^5]` 内（实际测试数据规模保证参考解在时限一半内跑完，单文件不超过 64KB）
- `0 <= Node.val <= 9`
