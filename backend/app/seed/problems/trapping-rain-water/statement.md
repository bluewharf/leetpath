## 题目描述

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 输入格式

第一行一个整数 `n`，表示柱子个数。

第二行 `n` 个整数 `height[0] .. height[n-1]`（`n=0` 时只有一行 `0`）。

## 输出格式

一行一个整数，表示能接的雨水总量。

## 样例

### 样例 1

输入：

```text
12
0 1 0 2 1 0 1 3 2 1 2 1
```

输出：

```text
6
```

### 样例 2

输入：

```text
6
4 2 0 3 2 5
```

输出：

```text
9
```

## 提示（数据范围）

- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
