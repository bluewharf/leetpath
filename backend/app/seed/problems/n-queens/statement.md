## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行、同一列或同一条斜线上的棋子。

**n 皇后问题**研究的是如何将 `n` 个皇后放置在 `n × n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n`，返回 n 皇后问题 **不同的解决方案的数量**。

本题只要求输出方案总数，不要求输出棋盘布局。

## 输入格式

一行一个整数 `n`。

## 输出格式

一行一个整数，表示不同解决方案的数量。

## 样例

### 样例 1

输入：

```text
4
```

输出：

```text
2
```

### 样例 2

输入：

```text
1
```

输出：

```text
1
```

## 提示（数据范围）

- `1 <= n <= 9`
