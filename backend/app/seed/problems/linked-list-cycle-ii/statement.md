## 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回空。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测时使用整数 `pos` 表示链表尾连接到链表中的位置（索引从 `0` 开始）。如果 `pos` 为 `-1`，则该链表没有环。`pos` 仅用于构造链表，不作为算法的输入参数。不允许修改给定的链表。

本题输出**入环节点的值**（不是下标）；若链表无环，则输出 `-1`。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值（此时尚未成环）。`n = 0` 时无节点值行。

最后一行一个整数 `pos`：

- `pos = -1` 表示无环；
- 否则 `pos` 为链表尾部 `next` 所连接节点的下标（从 `0` 开始），该下标对应的节点即为入环节点。

`n = 0` 时输入共两行：第一行 `0`，第二行 `pos`。

构造方式：先按节点值顺序创建 `n` 个节点并依次用 `next` 相连；若 `0 <= pos < n`，将尾节点的 `next` 指向下标为 `pos` 的节点，从而形成环。

## 输出格式

输出一行一个整数：入环节点的**值**；无环时输出 `-1`。

## 样例

### 样例 1

输入：

```text
4
3 2 0 -4
1
```

输出：

```text
2
```

链表为 `3 → 2 → 0 → -4`，尾节点连接到下标 `1` 的节点（值为 `2`），因此入环节点的值为 `2`。

### 样例 2

输入：

```text
2
1 2
0
```

输出：

```text
1
```

链表为 `1 → 2`，尾节点连接到下标 `0` 的节点（值为 `1`），因此入环节点的值为 `1`。

## 提示（数据范围）

- `0 <= n <= 10^4`（实际测试数据规模保证参考解在时限一半内跑完，单文件不超过 64KB）
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效下标
