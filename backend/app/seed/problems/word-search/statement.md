## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。

单词必须按照字母顺序，通过相邻单元格内的字母构成。相邻指四连通（上、下、左、右），不包括对角线。同一个单元格内的字母不允许被重复使用。

## 输入格式

第一行两个整数 `m` 和 `n`，表示网格的行数和列数。

随后 `m` 行，每行 `n` 个字符，空格分隔，表示网格 `board`。

最后一行一个字符串 `word`，表示要搜索的单词。

## 输出格式

输出一行：若存在路径构成该单词则输出 `true`，否则输出 `false`（小写）。

## 样例
### 样例 1
输入：
```text
3 4
A B C E
S F C S
A D E E
ABCCED
```
输出：
```text
true
```

### 样例 2
输入：
```text
3 4
A B C E
S F C S
A D E E
SEE
```
输出：
```text
true
```

## 提示（数据范围）

- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成
