## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。

你必须在不修改节点内部的值的情况下完成本题，即只能进行节点交换，而不能只交换节点中的值。若链表长度为奇数，最后一个节点保持原位。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。`n = 0` 时只有一行 `0`。

## 输出格式

第一行一个整数 `m`，表示交换后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，为空格分隔的节点值。空链表输出一行 `0`。

## 样例

### 样例 1

输入：

```text
4
1 2 3 4
```

输出：

```text
4
2 1 4 3
```

原链表为 `1 → 2 → 3 → 4`，两两交换后得到 `2 → 1 → 4 → 3`。

### 样例 2

输入：

```text
0
```

输出：

```text
0
```

空链表，交换后仍为空。

## 提示（数据范围）

- `0 <= n <= 100`
- `0 <= Node.val <= 100`
