## 题目描述

给你二叉树的根节点，返回其节点值的 **锯齿形层序遍历**：先从左往右，再从右往左，逐层交替进行。

空树不输出任何内容。普通层序（始终从左到右）见站点热题「二叉树的层序遍历」；本题是锯齿方向，不要当成同一题。

## 输入格式

输入一棵二叉树：第一行一个整数 `n`，第二行 `n` 个 token 为层序遍历序列，空位用 `null` 表示，末尾连续的 `null` 省略。空树输入为单行 `0`。

## 输出格式

按层输出节点值，每一层一行，同一层以空格分隔。偶数层（从 0 起）从左到右，奇数层从右到左。空树不输出任何内容。

## 样例

### 样例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
20 9
15 7
```

### 样例 2

输入：

```text
1
1
```

输出：

```text
1
```

## 提示（数据范围）

- 节点数不超过 `2000`
- `-1000 <= 节点值 <= 1000`
