## 题目描述

给你一个只包含正整数的非空数组 `nums`。判断是否可以将数组分割成两个子集，使两个子集的元素和相等。

两个子集和相等，当且仅当存在一个子集，其元素和为数组总和 `total` 的一半；若 `total` 为奇数，则不可能分割，应输出 `false`。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个正整数，空格分隔，表示 `nums`。

## 输出格式

输出一行：`true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
4
1 5 11 5
```

输出：

```text
true
```

解释：可以分割成 `[1, 5, 5]` 和 `[11]`，两子集和均为 `11`。

### 样例 2

输入：

```text
4
1 2 3 5
```

输出：

```text
false
```

解释：无法分割成两个元素和相等的子集。

## 提示（数据范围）

- `1 <= n <= 200`
- `1 <= nums[i] <= 100`
