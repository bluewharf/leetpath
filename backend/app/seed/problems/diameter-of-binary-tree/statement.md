## 题目描述

给定一棵二叉树，计算它的直径长度。

一棵二叉树的直径是任意两个结点之间路径长度的最大值。这条路径可能穿过根结点，也可能不穿过。两结点之间的路径长度以它们之间 **边的数目** 计，而不是结点数目。

空树的直径为 `0`；只有一个结点时直径也为 `0`。

## 输入格式

第一行一个整数 `n`，表示层序序列中的 token 个数。

若 `n = 0`，输入只有一行 `0`，表示空树。

若 `n > 0`，第二行 `n` 个 token，为二叉树的层序遍历：非空节点为整数，空位为 `null`。末尾连续的 `null` 省略。

## 输出格式

一行一个整数，表示直径（边的数目）。

## 样例

### 样例 1

输入：

```text
5
1 2 3 4 5
```

输出：

```text
3
```

解释：最长路径为 `4-2-1-3` 或 `5-2-1-3`，长度为 `3`（3 条边）。

### 样例 2

输入：

```text
2
1 2
```

输出：

```text
1
```

解释：最长路径为 `1-2`，长度为 `1`。

## 提示（数据范围）

- `0 <= n <= 10^4`（`n` 为层序 token 数；空树为 `n = 0`）
- `-100 <= 节点值 <= 100`
