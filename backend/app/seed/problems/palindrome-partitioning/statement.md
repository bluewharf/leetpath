## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成若干子串，使得每个子串都是 **回文串**。返回所有可能的分割方案。

回文串是正着读和倒着读都相同的字符串。

为保证输出确定：每种分割方案输出一行，同一方案内各段按从左到右的顺序、以空格分隔；所有行按字典序（Python 字符串比较）排序。

## 输入格式

一行，表示字符串 `s`。

## 输出格式

若干行，每行表示一种分割方案：各段以空格分隔。

所有行按字典序输出。

## 样例

### 样例 1

输入：

```text
aab
```

输出：

```text
a a b
aa b
```

### 样例 2

输入：

```text
a
```

输出：

```text
a
```

## 提示（数据范围）

- `1 <= |s| <= 16`
- `s` 仅由小写英文字母组成
