## 题目描述

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

最近公共祖先的定义为：对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。

## 输入格式

先输入一棵二叉树：第一行一个整数 `n`，第二行 `n` 个 token 为层序遍历序列，空位用 `null` 表示，末尾连续的 `null` 省略。
随后一行两个整数 `p` 和 `q`，表示两个指定节点的值。

保证所有节点值互不相同，`p != q`，且 `p`、`q` 均存在于树中。

## 输出格式

输出一个整数，即最近公共祖先的节点值。

## 样例

### 样例 1

输入：

```text
11
3 5 1 6 2 0 8 null null 7 4
5 1
```

输出：

```text
3
```

节点 5 和节点 1 的最近公共祖先是节点 3。

### 样例 2

输入：

```text
11
3 5 1 6 2 0 8 null null 7 4
5 4
```

输出：

```text
5
```

节点 5 和节点 4 的最近公共祖先是节点 5。因为根据定义，最近公共祖先节点可以为节点本身。

## 提示（数据范围）

- 树中节点数目在范围 `[2, 10^5]` 内
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中
