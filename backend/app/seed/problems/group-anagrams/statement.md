## 题目描述

给你一个字符串数组，请你将 **字母异位词** 组合在一起。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

为保证输出确定：每一组内的字符串按 **字典序** 排列；各组按该组 **第一个字符串的字典序** 排序；每组输出一行，组内以空格分隔。

## 输入格式

第一行一个整数 `n`，表示字符串个数。

随后 `n` 行，每行一个字符串（可以为空行，表示空字符串）。`n=0` 时只有一行 `0`。

## 输出格式

若干行，每行表示一组字母异位词（组内已按字典序排列，以空格分隔）。

各组按组内首元素的字典序输出。

若某组只含空字符串，则该行输出为空行。

若没有任何字符串，则不输出任何内容。

## 样例

### 样例 1

输入：

```text
6
eat
tea
tan
ate
nat
bat
```

输出：

```text
ate eat tea
bat
nat tan
```

### 样例 2

输入：

```text
1
```

输出：

```text
```

### 样例 3

输入：

```text
1
a
```

输出：

```text
a
```


## 提示（数据范围）

- `1 <= n <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅由小写英文字母组成（允许空字符串）
