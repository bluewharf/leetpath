## 题目描述

给定一个长度为 `n` 的非负整数数组 `nums`，你最初位于数组的第一个下标。

数组中的每个元素 `nums[i]` 表示从下标 `i` 向前跳转的最大长度。换句话说，如果你在下标 `i` 处，你可以跳到任意 `i + j` 处，满足：

- `0 <= j <= nums[i]`
- `i + j < n`

返回到达最后一个下标的最小跳跃次数。测试数据保证可以到达最后一个下标。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数，空格分隔，表示 `nums`。

## 输出格式

输出一个整数，表示到达最后一个下标的最小跳跃次数。

## 样例
### 样例 1
输入：
```text
5
2 3 1 1 4
```
输出：
```text
2
```

解释：从下标 0 跳 1 步到下标 1，再跳 3 步到达最后一个下标，共 2 次跳跃。

### 样例 2
输入：
```text
5
2 3 0 1 4
```
输出：
```text
2
```

## 提示（数据范围）

- `1 <= n <= 10^4`
- `0 <= nums[i] <= 1000`
- 测试数据保证一定可以到达最后一个下标
