## 题目描述

给你一棵二叉树的根节点 `root`，请翻转这棵二叉树，并返回翻转后的根节点。

翻转是指：对树中**每一个**节点，交换其左子树与右子树。可递归地对整棵树执行该操作。

## 输入格式

输入为一棵二叉树的层序序列：

- 第一行一个整数 `n`，表示层序 token 个数。
- 若 `n = 0`，输入只有一行 `0`，表示空树。
- 若 `n > 0`，第二行 `n` 个以空格分隔的 token：非空节点为整数，空位为 `null`。末尾连续的 `null` 已省略。

## 输出格式

输出翻转后的二叉树，序列化规则与输入相同：

- 空树输出一行 `0`。
- 非空树第一行输出 token 个数 `m`，第二行输出 `m` 个层序 token（空位为 `null`，**末尾连续的 `null` 必须省略**）。

## 样例

### 样例 1

输入：

```text
7
4 2 7 1 3 6 9
```

输出：

```text
7
4 7 2 9 6 3 1
```

### 样例 2

输入：

```text
3
2 1 3
```

输出：

```text
3
2 3 1
```

## 提示（数据范围）

- `0 <= n <= 200`
- `-1000 <= 节点值 <= 1000`

例如输入

```text
3
1 null 2
```

对应 `[1,null,2]`，翻转后为 `[1,2]`（右侧空位作为末尾连续 `null` 被省略），输出：

```text
2
1 2
```
