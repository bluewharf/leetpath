## 题目描述

给你链表的头节点，每 `k` 个节点一组进行翻转，返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯地改变节点内部的值，而是需要实际进行节点交换。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。

最后一行一个整数 `k`（`n = 0` 时，输入为两行：`0` 与 `k`）。

## 输出格式

第一行一个整数 `m`，表示结果链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，表示翻转后链表从前往后的节点值。

若结果为空链表，仅输出一行 `0`。

## 样例

### 样例 1

输入：

```text
5
1 2 3 4 5
2
```

输出：

```text
5
2 1 4 3 5
```

### 样例 2

输入：

```text
5
1 2 3 4 5
3
```

输出：

```text
5
3 2 1 4 5
```

## 提示（数据范围）

- `0 <= n <= 500`
- `n = 0` 时 `k >= 1`；`n > 0` 时 `1 <= k <= n`
- `0 <= 节点值 <= 1000`
