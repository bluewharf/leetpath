## 题目描述

给你一个按照**非递减顺序**排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `-1 -1`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

第三行一个整数 `target`。

## 输出格式

一行两个整数 `left right`，表示目标值第一次出现和最后一次出现的下标（从 0 开始），以空格分隔。

若不存在，输出 `-1 -1`。

## 样例

### 样例 1

输入：

```text
6
5 7 7 8 8 10
8
```

输出：

```text
3 4
```

解释：目标值 `8` 出现在下标 `3` 到 `4`。

### 样例 2

输入：

```text
6
5 7 7 8 8 10
6
```

输出：

```text
-1 -1
```

解释：目标值 `6` 不在数组中。

## 提示（数据范围）

- `0 <= n <= 10^5`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` 按非递减顺序排列
