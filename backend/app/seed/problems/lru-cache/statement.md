## 题目描述

请你设计并实现一个满足 **LRU（最近最少使用）缓存** 约束的数据结构。

缓存容量为固定正整数。当写入新键导致键的数量超过容量时，必须淘汰 **最久未使用** 的键。一次 **使用** 包括：成功的 `get`、写入新键的 `put`，以及对已存在键的 `put`（更新值）。

需要支持以下操作：

1. `LRUCache capacity`：以正整数 `capacity` 初始化缓存。
2. `put key value`：插入或更新。若 `key` 已存在，则更新其值，并将该键视为最近使用；若 `key` 不存在，则插入，并在超出容量时淘汰最久未使用的键。
3. `get key`：若 `key` 存在则返回其值，并将该键视为最近使用；若不存在则返回 `-1`。

`get` 与 `put` 均需以平均 `O(1)` 时间复杂度实现。

## 输入格式

第一行一个整数 `q`，表示操作数。

随后 `q` 行，每行一个操作，操作名与参数以空格分隔。操作集合如下：

- `LRUCache capacity`：以容量 `capacity` 初始化缓存。保证是第一条操作，且全程只出现一次。
- `put key value`：写入或更新键值对。
- `get key`：查询关键字 `key`。

无额外参数的操作只写操作名；本题目中每个操作都带有参数。

## 输出格式

**每个操作都按输入顺序输出恰好一行**：

- `LRUCache` 与 `put` 无返回值，输出 `null`。
- `get` 输出对应的整数值；关键字不存在时输出 `-1`。

## 样例

### 样例 1

输入：

```text
10
LRUCache 2
put 1 1
put 2 2
get 1
put 3 3
get 2
put 4 4
get 1
get 3
get 4
```

输出：

```text
null
null
null
1
null
-1
null
-1
3
4
```

说明：容量为 2。`put 1 1`、`put 2 2` 后缓存为 `{1=1, 2=2}`。`get 1` 返回 `1` 且 `1` 变为最近使用。`put 3 3` 淘汰最久未使用的 `2`。`get 2` 返回 `-1`。`put 4 4` 淘汰 `1`。随后 `get 1` 为 `-1`，`get 3` 为 `3`，`get 4` 为 `4`。

### 样例 2

输入：

```text
7
LRUCache 2
put 2 1
put 2 2
get 2
put 1 1
put 4 4
get 2
```

输出：

```text
null
null
null
2
null
null
-1
```

说明：对已存在的键再次 `put` 会更新值并视为最近使用，**不会增加** 缓存中的键数量。`put 2 1` 后再 `put 2 2`，缓存仍只有键 `2`（值为 `2`）。再写入 `1` 后缓存为 `{2=2, 1=1}`；`put 4 4` 淘汰最久未使用的 `2`，故最后 `get 2` 为 `-1`。

## 提示（数据范围）

- `1 <= capacity <= 3000`
- `1 <= q`，测试中 `q` 至多几千，单个用例不超过 64KB
- `0 <= key, value <= 10^4`
- 第一个操作一定是 `LRUCache`
