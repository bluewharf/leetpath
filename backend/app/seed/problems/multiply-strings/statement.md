## 题目描述

给定两个以字符串形式表示的非负整数 `num1` 和 `num2`，返回 `num1` 和 `num2` 的乘积，它们的乘积也表示为字符串形式。

不能使用任何内置的处理大整数的库，也不能直接把输入转换成整数类型。

## 输入格式

第一行字符串 `num1`。

第二行字符串 `num2`。

## 输出格式

一行，表示乘积的十进制字符串，除数字 `0` 本身外不含前导零。

## 样例

### 样例 1

输入：

```text
2
3
```

输出：

```text
6
```

### 样例 2

输入：

```text
123
456
```

输出：

```text
56088
```

## 提示（数据范围）

- `1 <= num1.length, num2.length <= 200`
- `num1` 和 `num2` 只包含数字 `0-9`
- `num1` 和 `num2` 均不含前导零，除非数字就是 `0`
