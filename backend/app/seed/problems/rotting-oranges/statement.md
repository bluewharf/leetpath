## 题目描述

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- `0` 表示空单元格；
- `1` 表示新鲜橘子；
- `2` 表示腐烂的橘子。

每分钟，腐烂橘子 **四方向**（上、下、左、右）相邻的新鲜橘子都会变成腐烂。

返回直到网格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`。

## 输入格式

第一行两个整数 `m` 和 `n`，表示网格的行数和列数。

随后 `m` 行，每行 `n` 个整数，空格分隔，表示网格 `grid`。

## 输出格式

输出一个整数：全部新鲜橘子腐烂所需的最少分钟数；若不可能则输出 `-1`。

## 样例

### 样例 1

输入：

```text
3 3
2 1 1
1 1 0
0 1 1
```

输出：

```text
4
```

### 样例 2

输入：

```text
3 3
2 1 1
0 1 1
1 0 1
```

输出：

```text
-1
```

解释：左下角的新鲜橘子永远不会腐烂，因为腐烂只会沿四方向传播。

### 样例 3

输入：

```text
1 2
0 2
```

输出：

```text
0
```


## 提示（数据范围）

- `1 <= m, n <= 10`
- `grid[i][j]` 为 `0`、`1` 或 `2`
- 若初始时已无新鲜橘子，答案为 `0`
