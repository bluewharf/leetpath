## 题目描述

给定一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典，判断是否可以利用字典中出现的一个或多个单词拼接出 `s`。

若能拼接出 `s` 则返回 `true`，否则返回 `false`。

注意：

- 不要求字典中的单词全部都被使用。
- 字典中的单词**可以重复使用**。例如 `s = "applepenapple"`、字典为 `apple` 与 `pen` 时，单词 `apple` 使用两次仍视为合法拼接。

## 输入格式

第一行一个非空字符串 `s`。

第二行一个整数 `m`，表示字典中的单词个数。

接下来 `m` 行，每行一个字典单词。

## 输出格式

输出一行 `true` 或 `false`（小写），表示 `s` 能否由字典中的单词拼接而成。

## 样例

### 样例 1

输入：

```text
leetcode
2
leet
code
```

输出：

```text
true
```

`s` 可以拆成 `"leet" + "code"`。

### 样例 2

输入：

```text
applepenapple
2
apple
pen
```

输出：

```text
true
```

`s` 可以拆成 `"apple" + "pen" + "apple"`。同一个单词 `apple` 被使用了两次，这是允许的。

## 提示（数据范围）

- `1 <= |s| <= 300`
- `1 <= m <= 1000`
- `1 <= |word| <= 20`
- `s` 和字典中的单词均由小写英文字母组成
- 字典中的单词互不相同
