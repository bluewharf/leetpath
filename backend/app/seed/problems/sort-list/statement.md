## 题目描述

给你链表的头结点 `head`，请将其按 **升序** 排列并返回排序后的链表。

## 输入格式

第一行一个整数 `n`，表示链表节点个数。

若 `n > 0`，第二行 `n` 个整数，表示链表从前往后的节点值。

若 `n = 0`，输入只有一行 `0`，表示空链表。

## 输出格式

第一行一个整数 `m`，表示排序后链表的节点个数。

若 `m > 0`，第二行 `m` 个整数，表示排序后链表从前往后的节点值。

若结果为空链表，仅输出一行 `0`。

## 样例

### 样例 1

输入：

```text
4
4 2 1 3
```

输出：

```text
4
1 2 3 4
```

### 样例 2

输入：

```text
5
-1 5 3 4 0
```

输出：

```text
5
-1 0 3 4 5
```

### 样例 3

输入：

```text
0
```

输出：

```text
0
```


## 提示（数据范围）

- `0 <= n <= 5 * 10^4`
- `-10^5 <= Node.val <= 10^5`
- 实际测试数据规模保证参考解在时限一半内跑完，单个用例文件不超过 64KB
