## 题目描述

给你二叉树的根节点，返回其节点值的层序遍历（即逐层地，从左到右访问所有节点）。

## 输入格式

输入一棵二叉树：第一行一个整数 `n`，第二行 `n` 个 token 为层序遍历序列，空位用 `null` 表示，末尾连续的 `null` 省略。空树输入为单行 `0`。

## 输出格式

按层输出节点值，每一层一行，同一层从左到右以空格分隔。空树不输出任何内容。

## 样例

### 样例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
9 20
15 7
```

### 样例 2

输入：

```text
1
1
```

输出：

```text
1
```

### 样例 3

输入：

```text
0
```

输出：

```text
```


## 提示（数据范围）

- 树中节点数目在范围 `[0, 2000]` 内
- `-1000 <= Node.val <= 1000`
