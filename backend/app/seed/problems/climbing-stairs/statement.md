## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶？

## 输入格式

一行一个整数 `n`，表示楼梯的阶数。

## 输出格式

输出一个整数，表示爬到楼顶的不同方法数。

## 样例
### 样例 1
输入：
```text
2
```
输出：
```text
2
```

解释：有两种方法可以爬到楼顶。

1. `1` 阶 + `1` 阶
2. `2` 阶

### 样例 2
输入：
```text
3
```
输出：
```text
3
```

解释：有三种方法可以爬到楼顶。

1. `1` 阶 + `1` 阶 + `1` 阶
2. `1` 阶 + `2` 阶
3. `2` 阶 + `1` 阶

## 提示（数据范围）

- `1 <= n <= 45`
