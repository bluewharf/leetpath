## 题目描述

给定整数数组 `coins` 表示不同面额的硬币，以及一个整数 `amount` 表示总金额。计算并返回可以凑成总金额所需的 **最少硬币个数**。如果无法凑成总金额，返回 `-1`。每种面额的硬币数量是无限的。

当 `amount = 0` 时，不需要任何硬币，返回 `0`。

## 输入格式

第一行一个整数 `n`，表示硬币面额种数。

第二行 `n` 个整数 `coins[0] .. coins[n-1]`（`n=0` 时只有一行 `0`）。

第三行一个整数 `amount`。

## 输出格式

一行一个整数：凑成总金额所需的最少硬币个数。无法凑成时输出 `-1`；`amount = 0` 时输出 `0`。

## 样例

### 样例 1

输入：

```text
3
1 2 5
11
```

输出：

```text
3
```

解释：`11 = 5 + 5 + 1`，最少使用 3 枚硬币。

### 样例 2

输入：

```text
1
2
3
```

输出：

```text
-1
```

解释：只用面额为 `2` 的硬币无法凑成 `3`，输出 `-1`。

### 样例 3

输入：

```text
1
1
0
```

输出：

```text
0
```


## 提示（数据范围）

- `1 <= n <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`
- 每种面额的硬币数量无限
- 无法凑成时输出 `-1`；`amount = 0` 时输出 `0`（不需要硬币）
- 实际测试数据规模保证参考解在时限一半内跑完，单文件不超过 64KB
