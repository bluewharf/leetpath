## 题目描述

给定一个二叉树的根节点 `root`，返回其最大深度。

二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

## 输入格式

第一行一个整数 `n`，表示层序序列中的 token 个数。

若 `n = 0`，输入只有一行 `0`，表示空树。

若 `n > 0`，第二行 `n` 个 token，为二叉树的层序遍历：非空节点为整数，空位为 `null`。末尾连续的 `null` 省略。

## 输出格式

一行一个整数，表示最大深度。空树的深度为 `0`。

## 样例

### 样例 1

输入：

```text
7
3 9 20 null null 15 7
```

输出：

```text
3
```

从根到叶子的最长路径为 `3 → 20 → 15`（或 `3 → 20 → 7`），节点数为 3。

### 样例 2

输入：

```text
3
1 null 2
```

输出：

```text
2
```

## 提示（数据范围）

- 树中节点数目范围是 `[0, 10^4]`
- `-100 <= Node.val <= 100`
