## 题目描述

给你两个链表，分别表示两个非负整数。它们每位数字都是按照**逆序**的方式存储的（最低位在链表头部），并且每个节点只存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

空链表表示数字 0。结果链表表示数值 0 时始终为单个节点 `0`（输出第一行 `1`、第二行 `0`），不会用空链表表示数值 0。

## 输入格式

先给出第一个链表：第一行整数 `n1`，表示节点个数。若 `n1 > 0`，第二行给出 `n1` 个整数（每位数字，低位在前）；若 `n1 = 0` 则该链表为空，视为数字 0，不再读入节点值。

再给出第二个链表：一行整数 `n2`，若 `n2 > 0` 则下一行 `n2` 个整数（每位数字，低位在前）；若 `n2 = 0` 则该链表为空，视为数字 0。

## 输出格式

第一行一个整数 `m`，表示结果链表的节点个数。

第二行 `m` 个整数，为空格分隔的各位数字（低位在前）。

数值 0 始终输出：

```text
1
0
```

## 样例

### 样例 1

输入：

```text
3
2 4 3
3
5 6 4
```

输出：

```text
3
7 0 8
```

解释：链表 `2 → 4 → 3` 表示 342，链表 `5 → 6 → 4` 表示 465，二者之和为 807，对应链表 `7 → 0 → 8`。

### 样例 2

输入：

```text
1
0
1
0
```

输出：

```text
1
0
```

解释：0 + 0 = 0。

## 提示（数据范围）

- `0 <= n1, n2 <= 100`
- `0 <= 数字位 <= 9`
- 题目数据保证列表表示的数字不含前导零（数字 0 本身除外）
