## 题目描述

给定一个经过编码的字符串 `s`，请返回它解码后的字符串。

编码规则为：`k[encoded_string]` 表示方括号内部的 `encoded_string` 恰好重复 `k` 次。`k` 为正整数。编码可以嵌套，例如 `3[a2[c]]` 表示将 `a2[c]` 重复 3 次，而 `2[c]` 表示将 `c` 重复 2 次。

可以认为输入总是有效的：没有多余空格，方括号成对出现。原始数据不含数字，数字只表示重复次数 `k`。不会出现形如 `3a` 或 `2[4]` 的输入。

## 输入格式

一行，表示编码字符串 `s`。

## 输出格式

一行，表示解码后的字符串。

## 样例

### 样例 1

输入：

```text
3[a]2[bc]
```

输出：

```text
aaabcbc
```

### 样例 2

输入：

```text
3[a2[c]]
```

输出：

```text
accaccacc
```

### 样例 3

输入：

```text
2[abc]3[cd]ef
```

输出：

```text
abcabccdcdcdef
```

### 样例 4

输入：

```text
abc3[cd]xyz
```

输出：

```text
abccdcdcdxyz
```


## 提示（数据范围）

- `1 <= |s| <= 30`
- `s` 由小写英文字母、数字和方括号 `[]` 组成
- `s` 保证是合法编码
- `s` 中出现的整数均在 `[1, 300]` 范围内
- 解码后字符串长度不超过 `10^5`
