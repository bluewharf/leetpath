## 题目描述

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 `s` 中涵盖 `t` 所有字符的最短子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串。

对于 `t` 中重复出现的字符，子串中该字符的出现次数必须不少于 `t` 中对应的次数。

子串是字符串中连续的一段非空字符序列。测试用例保证答案唯一。

## 输入格式

第一行一个字符串 `s`。

第二行一个字符串 `t`。

只去掉行尾换行符，其余字符均属于字符串本身。

## 输出格式

输出一行，即最短覆盖子串。若不存在这样的子串，输出空行。

## 样例

### 样例 1

输入：

```text
ADOBECODEBANC
ABC
```

输出：

```text
BANC
```

解释：最小覆盖子串 `"BANC"` 包含字符串 `t` 中的 `'A'`、`'B'` 和 `'C'`。

### 样例 2

输入：

```text
a
a
```

输出：

```text
a
```

解释：整个字符串 `s` 即为最小覆盖子串。

## 提示（数据范围）

- `1 <= |s|, |t| <= 10^5`，其中 `|s| = m`，`|t| = n`
- `s` 和 `t` 由英文字母组成（大小写敏感）
- 测试用例保证答案唯一
