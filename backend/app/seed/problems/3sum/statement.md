## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。

请你返回所有和为 `0` 且不重复的三元组。答案中不可以包含重复的三元组。

为保证输出确定：每个三元组内部按升序排列；所有三元组按字典序逐行输出，每行三个整数，以空格分隔。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

## 输出格式

若干行，每行一个三元组（三个升序整数，以空格分隔）。

所有三元组按字典序输出。

若没有任何三元组，则不输出任何内容。

## 样例

### 样例 1

输入：

```text
6
-1 0 1 2 -1 -4
```

输出：

```text
-1 -1 2
-1 0 1
```

### 样例 2

输入：

```text
3
0 1 1
```

输出：

```text
```

## 提示（数据范围）

- `3 <= n <= 3000`
- `-10^5 <= nums[i] <= 10^5`
