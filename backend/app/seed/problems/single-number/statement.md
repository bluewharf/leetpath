## 题目描述

给你一个 **非空** 整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数 `nums[0] .. nums[n-1]`（`n=0` 时只有一行 `0`）。

## 输出格式

一行一个整数，表示只出现一次的那个数字。

## 样例

### 样例 1

输入：

```text
3
2 2 1
```

输出：

```text
1
```

### 样例 2

输入：

```text
5
4 1 2 1 2
```

输出：

```text
4
```

### 样例 3

输入：

```text
1
1
```

输出：

```text
1
```


## 提示（数据范围）

- `1 <= n <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除一个元素只出现一次外，其余每个元素均出现两次
