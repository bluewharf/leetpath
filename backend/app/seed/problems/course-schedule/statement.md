## 题目描述

你这个学期必须选修 `n` 门课程，编号为 `0` 到 `n - 1`。

在选修某些课程之前需要一些先修课程。先修课程以二维整数数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` 表示如果要学习课程 `ai`，必须 **先** 学习课程 `bi`。

例如，先修对 `[0, 1]` 表示：想要学习课程 `0`，你需要先完成课程 `1`。

请你判断是否可能完成所有课程的学习。如果可以完成全部课程，输出 `true`；否则（图中存在环，无法排出合法修课顺序）输出 `false`。

## 输入格式

第一行一个整数 `n`，表示课程门数。

随后是先修关系构成的二维数组：第一行两个整数 `m` 和 `2`，其中 `m` 为先修对个数，第二维恒为 `2`。

若 `m > 0`，随后 `m` 行，每行两个整数 `ai bi`，表示修课程 `ai` 前必须先修课程 `bi`。若 `m = 0`，则只有一行 `0 2`，没有后续的先修对。

## 输出格式

输出一行：`true` 或 `false`（小写）。

## 样例

### 样例 1

输入：

```text
2
1 2
1 0
```

输出：

```text
true
```

共 2 门课。学习课程 `1` 前需先完成课程 `0`，不存在环，可以修完。

### 样例 2

输入：

```text
2
2 2
1 0
0 1
```

输出：

```text
false
```

学习课程 `1` 需先完成课程 `0`，学习课程 `0` 又需先完成课程 `1`，形成环，无法修完全部课程。

## 提示（数据范围）

- `1 <= n <= 2000`
- `0 <= m <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < n`
- `ai != bi`
- 所有先修对 `[ai, bi]` 互不相同
