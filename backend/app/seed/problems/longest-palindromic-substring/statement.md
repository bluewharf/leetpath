## 题目描述

给定一个字符串 `s`，请你找出 `s` 中最长的回文子串。

回文串是正着读和倒着读都相同的字符串。子串要求在原串中连续。

若存在多个长度相同的最长回文子串，输出其中 **字典序最小** 者。

## 输入格式

一行，表示字符串 `s`（可以为空行）。

## 输出格式

一行，表示最长回文子串。若存在多个最长回文子串（长度相同），输出其中字典序最小者。若 `s` 为空，输出空行。

## 样例

### 样例 1

输入：

```text
babad
```

输出：

```text
aba
```

解释：`bab` 与 `aba` 都是最长回文子串，按字典序取 `aba`（`aba` < `bab`）。

### 样例 2

输入：

```text
cbbd
```

输出：

```text
bb
```

## 提示（数据范围）

- `1 <= |s| <= 1000`
- `s` 仅由数字和英文字母组成
