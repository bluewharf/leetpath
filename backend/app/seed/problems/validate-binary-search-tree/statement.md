## 题目描述

给你一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树。

有效二叉搜索树定义如下：

- 节点的左子树只包含**严格小于**当前节点的数。
- 节点的右子树只包含**严格大于**当前节点的数。
- 左右子树自身也必须是二叉搜索树。

节点值相等则不是有效二叉搜索树。空树视为有效二叉搜索树。

## 输入格式

输入一棵二叉树：

- 第一行一个整数 `n`，表示层序序列中的 token 个数。
- 若 `n = 0`，输入只有一行 `0`，表示空树。
- 若 `n > 0`，第二行 `n` 个以空格分隔的 token：非空节点为整数，空位为 `null`。末尾连续的 `null` 已省略。

## 输出格式

输出一行 `true` 或 `false`（小写），表示该树是否为有效二叉搜索树。

## 样例

### 样例 1

输入：

```text
3
2 1 3
```

输出：

```text
true
```

### 样例 2

输入：

```text
7
5 1 4 null null 3 6
```

输出：

```text
false
```

根节点的值是 5，但是右子节点的值是 4。

## 提示（数据范围）

- 树中节点数目范围在 `[0, 10^4]` 内
- `-2^{31} <= Node.val <= 2^{31} - 1`
