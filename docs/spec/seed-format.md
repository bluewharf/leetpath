# 题库种子格式

每题一个目录：`backend/app/seed/problems/<slug>/`

```
<slug>/
├── meta.toml        # 元数据
├── statement.md     # 题面（Markdown，中文）
├── solution.md      # 题解（背题模式内容，入库）
├── reference.py     # 参考解（Python3，用于校验用例；不入库）
└── tests/
    ├── 001.in  001.out
    ├── 002.in  002.out
    └── ...          # 编号从 001 起连续递增
```

## meta.toml

```toml
slug = "two-sum"
title = "两数之和"
difficulty = "easy"        # easy | medium | hard
source = "hot100"          # hot100 | mianjing
tags = ["数组", "哈希表"]
time_limit_ms = 5000       # 可省，默认 5000
memory_limit_mb = 256      # 可省，默认 256
samples = [1, 2]           # 公开样例的用例编号（其余隐藏）
```

题面用中文；必须明确说明多解/顺序敏感题目的确定性输出规则（见下）。

## 统一 I/O 约定（ACM 模式，所有题必须遵守）

- 整数数组：第一行 `n`，第二行 `n` 个空格分隔整数（n=0 时只有一行 `0`）。
- 二维整数数组/矩阵：第一行 `m n`，随后 m 行各 n 个整数。
- 字符串：一行（可能为空行）。
- 链表：同整数数组（第一行 n，第二行 n 个值）；要求返回链表时同样按此格式输出值序列。
- 二叉树：第一行 `n`，第二行 n 个 token 为**层序遍历**，空位用 `null`，末尾连续的 null 省略；空树为单行 `0`。要求返回树时输出同样的层序序列（第二行，或空树输出 `0`）。
- 布尔输出：`true` / `false`（小写）。单值输出一行一个。数组输出：空格分隔一行。
- 浮点输出：统一保留 1 位小数（如 `2.0`）。
- **多解题**（全排列、子集、组合总和、括号生成、电话号码字母组合、分割回文串等）：每个结果序列化为一行，所有结果**按字典序输出**，每行一个。
- N 皇后：输出方案总数（整数一行）。
- 操作序列题（LRU 缓存、最小栈、Trie、数据流中位数）：第一行 `q` 为操作数；随后每行一个操作，格式 `opName arg1 arg2`（无参操作只有 opName）。有返回值的操作按顺序各输出一行（无返回输出 `null`）。具体 op 集合在题面中定义。
- 测试数据规模：保证 Python3 参考解在 time_limit 一半内跑完；单个 .in/.out 文件 ≤ 64KB。

## solution.md 结构（背题模式）

```markdown
## 思路

- 一句话点题（这题考什么 trick）
- 关键观察 / 不变量 / 为什么这样是对的（共 3-6 条，中文）

## 复杂度

- 时间：O(...)
- 空间：O(...)

## 模板代码

### Python3

​```python
# 完整 ACM 程序：读 stdin、写 stdout，必须能通过本题全部用例
​```

### C++

​```cpp
// 完整 ACM 程序（C++17），同样必须能通过全部用例
​```
```

要求：思路部分只讲"怎么想"，不复读题面；模板代码与 `reference.py` 逻辑等价但需是完整可提交的程序；两个代码块都必须是 fenced code block 且语言标记正确。

## 参考解与校验

- `reference.py` 从 stdin 读、向 stdout 写，必须是正确解。
- 校验器 `python scripts/validate_seed.py [slug...]`（仓库根目录运行，standalone 无三方依赖）：对每个（或指定）题目，逐用例运行 reference.py（超时 = 2×time_limit_ms），规范化比对（去行尾空白、去末尾空行）后与 .out 完全相等才算通过；任一失败则非零退出并打印明细。

## 生成要求（给内容生成者的硬性要求）

1. 每题 tests 至少：meta 中 `samples` 指定的 2 组样例 + **5~8 组隐藏用例**，覆盖边界（空/单元素/最大值/重复值/负数等按题意）。
2. 生成完必须本地跑 `python scripts/validate_seed.py <slug>` 通过才算完成。
3. 不改写题目本身语义；输入格式按上方约定从力扣函数签名风格转换为 ACM 风格，并在题面写清楚。
4. 题面仅供个人学习使用。
